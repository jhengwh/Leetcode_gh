## 169. Majority Element

### Boyer-Moore majority vote algorithm 摩爾(多數)投票演算法

<div align="center">
    <img src="https://raw.githubusercontent.com/jhengwh/Leetcode_gh/main/025_169_Majority-Element/169_image01.png" width = "600" alt="169_image01.png" align=center />
</div>
<br/>

- 因為 A (is the majority) 的數量超過一半，表示 A 的數量一定大於 B+C+D+… 的數量
- 每次移除兩個不同值
- 如果移除的是一個 “A” 與一個 “非A”，最後剩下的還是 A

<div align="center">
    <img src="https://raw.githubusercontent.com/jhengwh/Leetcode_gh/main/025_169_Majority-Element/169_image02.png" width = "600" alt="169_image02.png" align=center />
</div>
<br/>

- 如果移除的兩個都是 “非A” (e.g. B 與 C)，則會進一步讓 A 剩下更多
